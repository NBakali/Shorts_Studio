Shorts Studio

Shorts Studio is a private tool its owner uses to publish short news videos to the owner's own YouTube channel.

Privacy Policy

Shorts Studio uses the YouTube Data API only to upload and manage videos on its owner's own channel. It does not collect, store, share or sell any personal data from other people. The OAuth token it receives is stored only on the owner's private server and is used for nothing else. You can revoke access at any time at myaccount.google.com/permissions.
